The idea

Private adaptation.
Shared evidence.

FuseAdapt adapts a shared frozen vision backbone with lightweight, modality-specific low-rank branches. Query and value (Q/V) corrections stay private to each sensor. Only feedforward (FFN) low-rank residual activations are routed between available sensors.

Predictive Modality Modeling (PMM) teaches the model to predict a missing sensor’s representation from the visible ones. Its teacher and predictor are removed at inference.

01 / Method

Where adaptation becomes fusion

Two complementary mechanisms, inside one parameter-efficient framework.

A

Fuse available sensors

Receiver-conditioned, token-wise routing imports FFN residual activations from visible modalities. Missing sources are masked before routing weights are normalized.

Q/V adaptation stays modality-private.

B

Learn from the missing sensor

Target-specific queries predict the designated missing modality’s latent representation. A full-context exponential moving average (EMA) teacher supplies a detached training target.

The teacher and predictor add no inference-time cost.

What “adaptation-space” means. The contribution is a constraint on cross-modal information flow through low-rank residuals, not a new tensor domain. Routing and feature averaging require a common projected token grid.

Parameter efficiency, with measured deployment cost

At 1024 × 1024, batch 1 and FP32 on an H100, three-modality MiT-B0 FuseAdapt takes 21.05 ms, versus 19.63 ms for CMNeXt and 26.69 ms for StitchFusion. These timings use 20 warm-ups and 100 measured runs. Parameter efficiency does not imply the lowest latency or memory use.

04 / Research summary

Multimodal perception,
when sensors are missing.

FuseAdapt studies multimodal semantic segmentation with missing modalities: assigning a semantic label to each pixel when only a subset of the trained sensors is available. It uses parameter-efficient fine-tuning (PEFT) through low-rank adaptation (LoRA) on a frozen vision backbone.

Modality-specific Q/V updates preserve sensor-specific processing, while receiver-conditioned routing exchanges only FFN low-rank residual activations. Predictive Modality Modeling learns to infer a target sensor’s latent representation from visible sensor features using a full-context EMA teacher. Both the teacher and query predictor are removed after training.

Evaluation covers MCubeS, DELIVER, and MUSES, with modality-complete (MCSS) and modality-incomplete (MISS) protocols. Controlled MiT-B0/B2 experiments distinguish the fusion mechanism from the advantage of a stronger pretrained backbone. Robustness claims are limited to the evaluated missing-input subsets, predefined degradation conditions, and common-grid spatial-shift tests.

Research questions

How does FuseAdapt handle missing modalities?

It processes the available sensor subset, masks unavailable sources in cross-modal routing, and renormalizes routing weights. PMM trains missing-modality representation prediction but is removed at inference; the model does not need to generate a missing sensor’s raw input.

How is FuseAdapt different from shared LoRA or feature fusion?

Shared LoRA uses the same low-rank update across modalities. FuseAdapt assigns private Q/V updates to each sensor and routes FFN low-rank residual activations from source sensors to receiving sensors. It does not route complete dense FFN features or the parameter matrices themselves.

Is FuseAdapt restricted to DINOv2?

The paper evaluates frozen DINOv2, EVA-CLIP and NeCo representations, and adds controlled experiments using hierarchical MiT-B0 and MiT-B2 encoders. Effectiveness is supported on these evaluated backbones; it is not a guarantee for arbitrary architectures.

Does PMM solve arbitrary sensor misalignment?

No. FuseAdapt routing and averaging require a common projected token grid. Query prediction avoids same-index visible-to-target regression and is less sensitive to the tested spatial translations, but arbitrary field-of-view mismatch and temporal offsets are outside the evidence.
